# IELTS

> **Goal**: IELTS Academic — overall **Band 6.5**
> **Framework**: Simon Learning Method (skeleton) × SMART (goal-setting) × MECE (breakdown) × Feynman (review)

## 0. The method map

Simon is the **skeleton**; SMART and MECE are **tools used inside its steps**; Feynman closes the feedback loop.

```
Simon Learning Method（skeleton）
   │
   ├─ Step 1  Choose a field      ← ONE field: English
   │
   ├─ Step 2  Set a goal  ────────►  Tool: SMART
   │
   ├─ Step 3  Break it down ──────►  Tool: MECE
   │                                  (input line + output line)
   └─ Step 4  Sustain ~6 months   ← continuity, lean into the weakest skill
                                    Tool: Feynman  →  feedback loop
```

## 1. Choose a field (Simon Step 1)

**One field only: English — not "English + everything else".**

- **Why** — needed for study / work application, and long-term fluency.
- **How** — mock tests, vocabulary, daily output (write & speak).
- **What** — the four exam skills: Listening / Reading / Writing / Speaking.
- **20% first** — high-frequency vocabulary, question-type patterns, writing templates.

## 2. Set a goal (Simon Step 2 → SMART)

| Letter | Stands for | My definition |
| --- | --- | --- |
| **S** | Specific | Pass IELTS Academic with an overall Band 6.5 (no sub-score below 6.0) |
| **M** | Measurable | 1 mock test per week; 2 essays/week; 30 new words/day |
| **A** | Achievable | 2 hours/day + 4 hours on weekends, with my current workload |
| **R** | Relevant | Required for study / work application and long-term English fluency |
| **T** | Time-bound | Book and sit the exam within **6 months** |

> One-line version: *"Reach IELTS Academic overall Band 6.5 within 6 months, studying 2 hours a day."*

## 3. Break it down (Simon Step 3 → MECE)

Four independent skills — **no overlap, together they cover the whole exam** (MECE).

🟦 **Input line** (can self-check answers)

| Section | What it tests | Daily focus |
| --- | --- | --- |
| **Listening** | 4 parts, 40 questions | 1 section/day + shadowing |
| **Reading** | 3 passages, 40 questions | 1 passage/day, timed |

🟥 **Output line** (needs feedback — see Step 5)

| Section | What it tests | Daily focus |
| --- | --- | --- |
| **Writing** | Task 1 (report) + Task 2 (essay) | 2 essays/week, reviewed |
| **Speaking** | 3 parts, 11–14 min interview | 15 min/day speaking aloud + record |

> **Why split input vs output?** Input can be self-checked; output cannot. This is why
> Feynman (Step 5) is *mandatory* for Writing and Speaking, not optional.

## 4. Sustain it (Simon Step 4 · ~6 months)

Pick ONE field, bore one deep hole, keep continuity — but **lean into the weakest skill**, not just one section.

- **Weeks 1–8 · Foundation** — build vocabulary + grammar; learn question types for all 4 sections.
- **Weeks 9–16 · Practice** — one full mock per week; drill the **weakest** section.
- **Weeks 17–24 · Polish** — full timed mocks; review every mistake with the Feynman Technique.

### Weekly rhythm

| Day | Task |
| --- | --- |
| Mon–Fri | 2 hours: 1 section of the exam + 30 words |
| Sat | Mock test (one section) + review |
| Sun | Writing correction + speaking practice + weekly review |

## 5. Review loop (Feynman) — the feedback Simon doesn't cover

For every mistake — **especially in Writing and Speaking** — don't just re-read. **Teach it back**:

1. Write down what you got wrong in plain English.
2. Explain why the correct answer is right, as if to a beginner.
3. If you stumble, go back to the source and simplify again.

> **Track it**: keep a running "mistake log". Anything that keeps recurring becomes next week's focus.
