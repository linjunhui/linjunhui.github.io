# Eisenhower Matrix

## Mindset 003｜Eisenhower Matrix (四象限法则) — Explained

**In one sentence**: Sort every task by two axes — **Important** and **Urgent** — into four
quadrants, then act differently in each, so your time goes to what actually matters.

**Why it matters**: Most people are run by whatever is *loudest*, not what is *most valuable*.
The matrix makes the trade-off visible, so you can choose deliberately.

## How it reads in a table

| | **Urgent** | **Not Urgent** |
| --- | --- | --- |
| **Important** | **① Do it now** — firefighting | **② Schedule it** — growth |
| **Not Important** | **③ Delegate / fast** — distraction | **④ Don't do it** — waste |

## How to actually use it

1. **Brain-dump** — list everything on your plate, no filtering.
2. **Tag** — mark each item Important? Urgent? (both, either, neither).
3. **Assign a quadrant action** — now / schedule / delegate / drop.
4. **Lock ② into the calendar** — a "②" that isn't scheduled will always lose to a "①".
5. **Review weekly** — check the ② items actually got time; re-sort as things change.

> **The one trap**: urgency feels like importance. The loudest task is usually ① or ③ —
> the quiet, high-value work is almost always ②.

## How it connects to my other methods

These three solve **different** questions — together they form one chain:

| Method | The question it answers | Role |
| --- | --- | --- |
| **Eisenhower Matrix** | *Where should my time go?* | **Choose priority** |
| **[SMART Principle](SMART-Principle.md)** | *How do I define the goal clearly?* | **Set the goal** |
| **[Simon Learning Method](learning-ability_Simon-learning-method.md)** | *How do I stay with it and go deep?* | **Execute** |

**Worked example — IELTS:**

- **Matrix** → "Pass IELTS" is **② Important + Not Urgent**.
- **SMART** → turn it into *"Band 7.0 in 12 weeks, 20 hours/week"*.
- **Simon** → pick one field, break it down (MECE), sustain continuously.

Without the matrix, IELTS never gets scheduled — it keeps being pushed by ①③ until it
suddenly becomes a **① urgent** firefight a month before the exam.

## One-line memory

> **忙 ≠ 重要。** 压缩③④，把时间投进②；②要排进日历，否则永远被①挤掉。
