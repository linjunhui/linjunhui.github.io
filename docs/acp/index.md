# Alibaba Cloud ACP

> Target: **Alibaba Cloud Certified Professional (ACP)**
> Method: **SMART goal × Simon Learning Method**

## 1. Set the goal (SMART)

| Letter | Stands for | My definition |
| --- | --- | --- |
| **S** | Specific | Pass the Alibaba Cloud ACP certification exam |
| **M** | Measurable | Finish the official course + pass 3 practice exams ≥ 80% |
| **A** | Achievable | ~1.5 hours/day, alongside my current workload |
| **R** | Relevant | Validates cloud skills for my work and projects |
| **T** | Time-bound | Book and sit the exam within **3 months** |

## 2. Break it down (MECE)

| Module | Focus |
| --- | --- |
| **Compute** | ECS, containers, auto-scaling |
| **Storage & Network** | OSS, VPC, SLB, DNS |
| **Database** | RDS, Redis, PolarDB |
| **Security & Ops** | RAM, monitoring, backup & recovery |

## 3. Sustain it

- **Weeks 1–4** — work through the official course, module by module.
- **Weeks 5–8** — hands-on labs + practice exams.
- **Weeks 9–12** — review weak modules with the **Feynman Technique**, then take mock exams.
